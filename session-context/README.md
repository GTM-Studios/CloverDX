# session-context/

Saved context from AI working sessions on this repo — so a new session can pick up where a previous one left off instead of starting cold.

## What goes here

- One file per saved session (or per meaningful chunk of work), covering: what was worked on, key decisions/findings, and what's still open.

## Naming convention

`YYYY-MM-DD-topic.md`, e.g.:

- `2026-09-08-first-sourcing-review.md`
