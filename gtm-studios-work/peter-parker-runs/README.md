# peter-parker-runs/

Each scraper run gets its own dated folder, e.g. `YYYY-MM-DD-<segment>-<pass>/` containing:

- `input-<n>-domains.csv` — the input domains/companies
- `prompt-as-run.md` — the prompt exactly as executed
- `results-<n>-domains.csv` — the structured output
- `README.md` — what the run was, decisions, data-quality warnings
- `DATA-QUALITY-WARNING.md` — any known quality issues with the run
